# RSS 리더 확장 프로그램 - E2E 테스트 시나리오

## 1. 피드 관리 (Options 페이지)

### TC-01: 새 피드 추가
1.  **Given**: 옵션 페이지에 접속한다.
2.  **When**: 유효한 RSS URL(예: `https://www.theverge.com/rss/index.xml`)을 입력하고 'Add Feed' 버튼을 클릭한다.
3.  **Then**: 피드 목록에 해당 URL이 표시된다.

### TC-02: 중복 피드 추가 시도
1.  **Given**: 옵션 페이지에 특정 피드가 이미 추가되어 있다.
2.  **When**: 동일한 URL을 다시 입력하고 'Add Feed' 버튼을 클릭한다.
3.  **Then**: "This feed has already been added." 경고창이 표시된다.

### TC-03: 피드 삭제
1.  **Given**: 옵션 페이지에 하나 이상의 피드가 추가되어 있다.
2.  **When**: 특정 피드 항목의 'Remove' 버튼을 클릭한다.
3.  **Then**: 해당 피드가 목록에서 사라진다.

### TC-04: OPML 파일로 피드 가져오기 (Import)
1.  **Given**: 옵션 페이지에 접속한다.
2.  **When**: `outline` 태그를 포함한 유효한 OPML 파일을 'Import from OPML'에 업로드한다.
3.  **Then**: OPML 파일에 포함된 피드 URL들이 목록에 추가되고, 성공했다는 경고창이 표시된다.

### TC-05: OPML 파일로 피드 내보내기 (Export)
1.  **Given**: 옵션 페이지에 하나 이상의 피드가 추가되어 있다.
2.  **When**: 'Export to OPML' 버튼을 클릭한다.
3.  **Then**: `rss_feeds.opml` 파일 다운로드가 시작된다.

## 2. 피드 확인 (Popup 페이지)

### TC-06: 팝업 실행 및 피드 로드 확인
1.  **Given**: 백그라운드에서 피드 동기화가 완료되었다.
2.  **When**: 툴바의 확장 프로그램 아이콘을 클릭하여 팝업을 연다.
3.  **Then**: 'Loading feeds...' 메시지가 사라지고, 하나 이상의 피드 아이템이 표시된다.

### TC-07: 기사 제목 클릭 (읽음 처리 및 새 탭 열기)
1.  **Given**: 팝업에 읽지 않은 상태의 기사 목록이 표시된다.
2.  **When**: 특정 기사의 제목을 클릭한다.
3.  **Then**: 해당 기사의 원문 링크가 새 탭으로 열린다.
4.  **And**: 팝업에서 해당 기사 항목이 'read' 상태(흐리게 표시)로 변경된다.

### TC-08: 리더 뷰 실행
1.  **Given**: 팝업에 기사 목록이 표시된다.
2.  **When**: 특정 기사의 'Read' 버튼을 클릭한다.
3.  **Then**: 리더 뷰 모달이 나타나고, 기사 제목과 본문이 표시된다.
4.  **And**: 모달의 닫기 버튼을 클릭하면 모달이 사라진다.

### TC-09: 검색 기능
1.  **Given**: 팝업에 여러 기사가 표시된다.
2.  **When**: 검색창에 특정 키워드(예: 'Apple')를 입력한다.
3.  **Then**: 제목 또는 피드 URL에 해당 키워드가 포함된 기사만 표시된다.

### TC-10: 정렬 기능
1.  **Given**: 팝업에 여러 기사가 표시된다.
2.  **When**: 정렬 드롭다운을 'Oldest First'로 변경한다.
3.  **Then**: 가장 오래된 기사가 목록 최상단에 표시된다.
4.  **When**: 정렬 드롭다운을 'By Score'로 변경한다.
5.  **Then**: 낚시성 점수가 낮은(부정적인) 기사가 목록 하단으로 정렬된다.

### TC-11: 'Unread only' 필터 토글
1.  **Given**: 팝업에 읽은 기사와 읽지 않은 기사가 섞여 있다.
2.  **When**: 'Unread only' 체크박스를 해제한다.
3.  **Then**: 읽음 처리된 기사들이 목록에 함께 표시된다.
4.  **When**: 'Unread only' 체크박스를 다시 선택한다.
5.  **Then**: 읽음 처리된 기사들이 목록에서 사라진다.
